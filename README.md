## Domínio
  Moda Alternativa

## Dores do Cliente
  1. Dificuldade em encontrar moda alternativa na própria região;

2. Preços incompatíveis com o público;

3. Falta de um brechó especializado;

4. Pesquisa demorada;
   
5. Dificuldade em encontrar um estilo específico;

6. Falta de identidade visual;

7. Pouca sustentabilidade no nicho.
  
## Solução do Problema
  Promover a influência da estética alternativa, tornando estilos e culturas mais acessíveis para pessoas que não possuem condições, seja por carência monetária, por não encontrar estruturas que promovem esse tipo de comércio ou por inseguranças; criar um website torna a causa mais acessível para as pessoas em geral

## Requisitos
### Requisitos Funcionais
RF01: O sistema deve permitir o cadastro e login de usuários
RF02: O sistema deve ser responsivo para outros dispositivos
RF03: O sistema deve possuir uma interface prática e intuitiva
RF04: O sistema deve permitir ao usuário à gestão de dados de sua conta
RF05. O sistema deve permitir recuperação de senha. 
RF06: O sistema deve permitir cadastrar itens.
RF07: O sistema deve permitir editar itens cadastrados.
RF08: O sistema deve permitir excluir itens.
RF09: O sistema deve listar os itens cadastrados.
RF10: O sistema deve permitir pesquisar itens;
RF11: O sistema deve possuir a filtragem de itens;
RF12: O sistema deve exibir detalhes de itens;
RF13: O sistema deve possuir um funcionalidade de notificações ao usuário.
RF14: O administrador deve poder gerenciar usuários.
RF15: O administrador deve poder gerenciar conteúdos cadastrados.
RF16: O administrador deve visualizar relatórios do sistema.
RF17: O sistema deve registrar logs das principais operações.
### Requisitos Não-Funcionais
RNF01: O sistema deve ser responsivo.
RNF02: O sistema deve utilizar autenticação segura.
RNF03: O tempo de resposta das consultas deve ser inferior a 3 segundos.
RNF04: O sistema deve ser compatível com Chrome, Edge e Firefox.
RNF05: O sistema deve proteger os dados dos usuários conforme a legislação vigente.
RNF06: O sistema deve possuir interface intuitiva.
RNF07: O sistema deve realizar backup periódico do banco de dados.
RNF08: O sistema deve estar disponível continuamente, exceto durante manutenções programadas.
